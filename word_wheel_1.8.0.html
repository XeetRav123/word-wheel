Аккаунты музыки

Твоя музыка попадёт в избранное, каждый плейлист станет категорией. Играет через YouTube, Deezer и Apple: сами сервисы аудио не отдают.

Spotifyне привязан
Как привязать
  1. Открой developer.spotify.com/dashboard и создай приложение (бесплатно).
  2. В поле Redirect URI впиши: http://127.0.0.1:8888/callback
  3. Скопируй Client ID сюда и нажми «Войти».
  4. После входа браузер покажет ошибку страницы — так и должно быть. Скопируй адрес из его строки и вставь ниже.
Открыть вход вручную
YouTube / YouTube Musicне привязан

Самое простое: вставь ссылку на плейлист (публичный или по ссылке). Свою «Понравившуюся» музыку можно скопировать в такой плейлист в приложении.

Войти в Google (экспериментально)
  1. В console.cloud.google.com включи YouTube Data API v3 и создай OAuth-клиент типа «Приложение для компьютера».
  2. Добавь себя в тестовые пользователи экрана согласия.
  3. Вставь Client ID и секрет, нажми «Войти», затем вставь адрес из строки браузера.
  4. Google может не разрешить обмен кода из страницы (CORS) — тогда останется импорт по ссылке.
